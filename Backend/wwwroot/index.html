Alur Kerja & Pencegahan Kegagalan Mode Offline

Area tambang memiliki banyak blind-spot tanpa jangkauan 4G/Wi-Fi. Backend Indexsafe Evolution menerapkan protokol sinkronisasi berbasis Outbox Pattern dengan jaminan data integrity sebagai berikut:

1
Pencatatan Offline di Pit
Pekerja mengisi form (Inspeksi/P2H/Hazard) dan memotret temuan. Data disimpan ke SQLite lokal (isafe18.db) dengan sync_id = NULL.
2
Perekaman GPS Satelit
Koordinat GPS (lat, long, accuracy) diambil langsung via sensor satelit GNSS handphone tanpa memerlukan koneksi internet, lalu disematkan ke field lokasi.
3
Outbox Sweep (Background Sync)
Saat HP mendeteksi koneksi Wi-Fi mess atau 4G, background job mengeksekusi POST /api/tran/{name} mengunggah baris transaksi lokal secara berurutan.
4
Idempotency & Anti-Duplikasi
Jika sinyal timbul-tenggelam menyebabkan mobile melakukan retry berkali-kali, backend mengecek client_uuid / duplikat payload dan mengembalikan Server ID yang sama tanpa double-insert.
5
Detail & Action Plan Auto-Link
Setelah header mendapat Server ID (misal: 8801), detail checklist di-upload dengan ref_id = 8801, dan Action Plan otomatis dibuka untuk ditindaklanjuti oleh PJA.
